The repo skeleton

The folder you open is the thing you're changing. Five kinds of folder, each with one shape, decided up front.

Rules the build enforces

SizeOver 300 lines fails. A folder grows by adding a part.
Directionareas → kit, domain, commands. jobs → domain, data. domain → nothing.
RegistrationSidebar, ⌘K, E.V.'s tools and Activity are generated from area.ts and job.ts.
ShapeA component without a story and test, or a job without a cost cap, fails.
TokensNo raw colour or size outside kit/tokens. Views compose, never style.
One rules fileCONTRACT.md. Decisions, backlog and changelog are generated.
